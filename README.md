# 🏠 House Price Prediction using Machine Learning

This project predicts house prices based on the area of the house using a **Linear Regression** machine learning model.

It is a beginner-friendly end-to-end ML project developed using **Python**, executed in **VS Code**, and hosted on **GitHub**.

---

## 📌 Problem Statement
To build a machine learning model that can predict the price of a house based on its area (in square feet).

---

## 🧠 Machine Learning Algorithm
- **Linear Regression**
- Supervised Learning
- Regression Problem

## 📊 Dataset Description
The dataset contains two columns:
- **Area** – Size of the house (in sq.ft)
- **Price** – Price of the house

Sample data:
Area: 500 → Price: 100000
Area: 1000 → Price: 200000

## ▶️ How to Run the Project

1. Clone or download the repository
2. Open the folder in VS Code
3. Install dependencies:
pip install -r requirements.txt

4. Train the model:python model/train_model.py
5. Run the application:python app.py


---

## ✅ Output
The model predicts the house price based on user input area.

Example:
Enter house area: 1200
Predicted Price: 240000
